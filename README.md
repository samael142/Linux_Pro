Работа с NFS

Скрипт nfs_server.sh устанавливает NFS сервер, содзаёт директорю и экспортирует её.
Скрипт nfs_client.sh устанавливает NFS клиент, монтирует директорию с сервера.


1. Из под root на серевере запустить nfs_server.sh
2. Из под root на серевере запустить nfs_client.sh, предварительно указав в переменной $NFS_SERVER адрес сервера из п.1
